# 🧁 ระบบจัดการร้านขนม

เว็บแอปสำหรับคนทำขนมขายเป็นอาชีพเสริม — แทนการจดบัญชีกระจัดกระจาย
ด้วยตัวเลขต้นทุนจริงที่ **รวมค่าแรงและเวลา** ไม่ใช่แค่ค่าวัตถุดิบ

**ข้อมูลเก็บในเครื่องผู้ใช้ทั้งหมด** ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัคร ไม่ต้องล็อกอิน
เปิดใช้ได้แม้ไม่มีเน็ต

## หลักคิดของแอปนี้

```
ต้นทุนจริงต่อชิ้น = (วัตถุดิบ + ค่าแรง + ค่าแฝง) ÷ จำนวนที่ได้ต่อรอบ

กำไรขั้นต้น = ยอดขาย − ต้นทุนวัตถุดิบ
กำไรสุทธิ   = ยอดขาย − ต้นทุนจริงต่อชิ้น − ส่วนแบ่งช่องทาง − ค่าส่ง
```

ทุกหน้าแสดง **สองตัวเลขคู่กันเสมอ** เพราะช่องว่างระหว่างมันคือค่าแรงที่มัก
ถูกลืม เช่น บราวนี่ 24 ชิ้น (วัตถุดิบ 380 · แรง 3.5 ชม.×150 · แฝง 120)
ขาย 10 ชิ้นราคา 60 ฝากร้านหัก 30% ค่าส่ง 50:

| | |
|---|---|
| กำไรขั้นต้น | **+441.67** ← ดูเหมือนได้กำไร |
| กำไรสุทธิ | **−57.08** ← ความจริงคือขาดทุน |

## 💾 สำรองข้อมูล

ข้อมูลอยู่ในเครื่องเดียว **ถ้าลบแอปออกจากหน้าจอ ข้อมูลหายทั้งหมด**

หน้า **ตั้งค่า** มีปุ่ม:
- **⬇ สำรองข้อมูลตอนนี้** — ได้ไฟล์ `.json` ส่งเข้าแชทตัวเองหรือเก็บใน iCloud Drive
- **⬆ กู้จากไฟล์** — เอาไฟล์นั้นกลับมาใส่เครื่องใหม่ได้

แนะนำให้สำรองเดือนละครั้ง หรือหลังบันทึกข้อมูลเยอะ ๆ

## Stack

- **Next.js 15** static export — ไม่มีเซิร์ฟเวอร์ เป็นไฟล์นิ่ง ๆ ล้วน
- **Dexie / IndexedDB** — ฐานข้อมูลในเบราว์เซอร์
- **Tailwind CSS v4**
- **PWA** — service worker ทำให้เปิดใช้ได้ตอนไม่มีเน็ต

## ลำดับการใช้งาน

1. **ตั้งค่า** — ใส่ค่าแรงต่อชั่วโมงของตัวเองก่อนเป็นอันดับแรก
2. **สินค้า** — เพิ่มขนมแต่ละชนิด + ราคาขายมาตรฐาน
3. **ช่องทาง** — ขายเอง / ฝากร้าน (หัก %) / ส่งราคาคงที่
4. **รอบผลิต** — ทุกครั้งที่ทำขนม บันทึกวัตถุดิบ+เวลา+จำนวนที่ได้
   → เห็นต้นทุนจริงต่อชิ้นทันทีระหว่างกรอก และตัดเข้าสต๊อกอัตโนมัติ
5. **ขาย/ฝาก** — เลือกสินค้า+ช่องทาง+จำนวน → ตัดสต๊อก คิดกำไรให้
6. **รายงาน** — ดูว่าขนมชนิดไหน/ช่องทางไหนคุ้มแรงจริง

> ถ้าไม่ตั้งค่าแรง กำไรสุทธิจะเท่ากับกำไรขั้นต้น
> แล้วแอปนี้ก็จะไม่ต่างจากสมุดจดเล่มเดิม

## รายละเอียดที่ตั้งใจออกแบบไว้

- **ค่าแรงถูก snapshot ติดไปกับแต่ละรอบผลิต** — ปรับค่าแรงวันนี้
  รอบผลิตเก่าไม่เปลี่ยนตาม ประวัติกำไรจึงยังตรงกับความจริง
- **ต้นทุนถูก snapshot ตอนขาย** ด้วยค่าเฉลี่ยถ่วงน้ำหนักจากทุกรอบผลิต —
  ผลิตรอบใหม่ราคาต่างออกไป กำไรของรายการเก่าไม่ขยับ
- **สต๊อกคำนวณสดจาก ผลิต − ขาย** ไม่ได้เก็บเป็นตัวเลขนิ่ง ๆ จึงไม่มีทาง
  เพี้ยนแม้จะลบหรือแก้รายการย้อนหลัง
- **วัตถุดิบกรอกได้ 2 แบบ** — ยอดรวมรอบนี้ (เร็ว) หรือแยกทีละอย่าง (ละเอียด)
- **ลบสินค้าที่มีประวัติขาย จะเปลี่ยนเป็นปิดการใช้งานแทน** เพื่อไม่ให้รายงาน
  ย้อนหลังพัง

## พัฒนาต่อ

```bash
npm install
npm run dev      # เปิด http://localhost:3000
npm test         # ตรวจสูตรคำนวณ 22 เคส
npm run build    # ได้ไฟล์ static ใน out/
```

สูตรคำนวณทั้งหมดอยู่ใน [`src/lib/calc.ts`](src/lib/calc.ts) และมีชุดทดสอบ
ที่ [`test/calc.test.mjs`](test/calc.test.mjs) — ตัวเลขคาดหวังทุกตัวคือค่าที่
PostgreSQL 18 จริงเคยคืนมาตอนระบบยังใช้ฐานข้อมูลบนคลาวด์
ถ้าแก้สูตร ต้องรันเทสต์ผ่านก่อนเสมอ

## ข้อจำกัดที่ยอมรับ
